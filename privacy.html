사용 범위

이 앱은 소유자 한 사람만 쓰는 개인 백업 도구입니다. 소유자 본인의 PC에서 소유자 본인의 Google Drive 로 백업 파일을 올리고, 올라간 파일을 확인·정리하는 데에만 Google Drive 접근 권한을 씁니다.

수집·공유하지 않는 것

제3자의 개인정보를 수집하지 않습니다. Google 사용자 데이터를 다른 곳으로 보내거나, 팔거나, 광고에 쓰거나, 다른 사람과 공유하지 않습니다. 인증 정보는 소유자 PC 안의 rclone 설정 파일에만 저장됩니다.

Scope of use

This app is a personal backup tool used by a single owner. It uses Google Drive access only to upload backup files from the owner's computer to the owner's own Google Drive and to list and clean up those files.

What is not collected or shared

No personal data of any third party is collected. Google user data is not transferred, sold, used for advertising, or shared with anyone. Credentials are stored only in the rclone configuration file on the owner's computer.

Access removal

Access can be revoked at any time at myaccount.google.com/connections.
